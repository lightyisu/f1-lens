# F1 Lens

F1 Lens is a simple way to get Formula 1 schedules, race results, and session analysis — with a clean, minimal presentation.

Unofficial fan project. Not affiliated with Formula 1.

## Features

- Season schedule with next-race countdown and live/ended session status
- Race results & qualifying (grid gains/losses, fastest lap)
- Post-race analysis (lap times, tyre strategy, weather, race control) via OpenF1
- Chinese / English UI

## Stack

- Next.js · React · Tailwind CSS
- Data: Jolpica (Ergast-compatible) · OpenF1 · F1 SessionInfo

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
